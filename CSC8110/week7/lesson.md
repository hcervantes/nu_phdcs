### Assignment 7 — Develop a Computer Program for a Scenario
**Due: Dec 13, 2026 11:59 PM · 15 points · Turnitin enabled**

#### Assignment Instructions
**Problem:** What is the perimeter of a room given the width and area? Width = 8 feet; area = 80 square feet. There are two ways to solve it:
1. Use the equations that compute the area and perimeter.
2. Draw a diagram of the problem.

Your paper must include:

- An explanation of the problem (understand the problem).
- Two plans, one for each scenario.
- An algorithm for each scenario, including all steps of the solution.
- A computer program for each scenario (any language: C, Python, Java, etc.).
- Execution of the code (run it and show results).
- A look back at both solutions: determine which is better, backed up with reasoning.
- **Length:** 3–5 pages (excluding title and references) · **References:** ≥2 scholarly resources · APA.

#### Assignment Outline & Writing Inspiration
1. **Understand the problem (~0.5 pg)** — Restate: knowns (width 8 ft, area 80 sq ft), unknown (perimeter). Show the quantitative reasoning: length = area ÷ width = 80 ÷ 8 = **10 ft**; perimeter = 2 × (width + length) = 2 × (8 + 10) = **36 ft**.
2. **Two plans (~0.5 pg)** — Plan 1 (equations): derive length from area, then perimeter formula. Plan 2 (diagram): draw the room to scale, read the length geometrically, then compute the perimeter.
3. **Algorithm 1 — equations (~0.5 pg)** — All steps: input width & area → length = area/width → perimeter = 2(width+length) → output. No code here.
4. **Algorithm 2 — diagram (~0.5 pg)** — Steps: draw rectangle to scale → verify area visually → measure/derive length → compute perimeter.
5. **Programs + execution (~1 pg)** — Two actual programs (e.g., Python), each with code and its executed output (screenshots or captured runs). Verify both print 36.
6. **Look back: which is better? (~0.75 pg)** — Inspiration: the equation solution is exact, fast, generalizable to any inputs, and automatable; the diagram aids intuition and validation but doesn't scale. Back your choice with reasoning and ≥2 scholarly sources (problem-solving / quantitative reasoning literature).
7. **Conclusion & references.**
