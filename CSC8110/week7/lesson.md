## Assignment Due This Week

### Assignment 7 — Room Perimeter Program (Code + Paper)
**Due: Dec 13, 2026 · 15 points · 3–5 pages · scholarly references**

**Scenario:** Calculate the perimeter of a room given width = 8 feet and area = 80 square feet.

**Outline:**
1. **Solution 1 — mathematical equations:**
   - Derive length = area ÷ width = 80 ÷ 8 = 10 ft
   - Perimeter = 2 × (width + length) = 2 × (8 + 10) = 36 ft
   - Write the algorithm and implement the code (any language).
2. **Solution 2 — diagrammatic representation:**
   - Diagram the room and solve the perimeter geometrically.
3. **Execution** — run the program and capture results.
4. **Comparison of solutions** — accuracy, clarity, effort, and when each approach is preferable.
5. **Conclusion & references** (3–5 page academic format).
