# Week 2: Procedural vs. Object-Oriented Languages

**Dates:** Nov 2 – Nov 8, 2026 · **Module:** 1 · **Focus:** Syntax, semantics & compilation

## Learning Objectives
- Compare syntax, semantics, use, and structure of procedural vs. OO languages.
- Explain the compilation process: lexical analysis, variable handling, control structures.

## Key Topics
- Procedural programming (Pascal, C): step-by-step logic, process over data, IDEs (Visual Studio).
- Object-oriented programming (Java, C++): classes, objects, modularity, reusability, data hiding.
- Key differences: abstraction, inheritance, development time, maintainability.
- Compilation pipeline: lexical analyzer → parser → code generation; bytecode vs. native code.
