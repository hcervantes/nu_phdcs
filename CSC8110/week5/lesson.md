#### Assignment Outline & Writing Inspiration
1. **Introduction (~0.75 pg)** — Why sorting is a benchmark problem; thesis: algorithm choice directly drives processor, memory, and energy costs.
2. **Algorithms & computing power (~1.5 pg)** — Cover every required dimension: processor performance, data retrieval, processing, storage and distribution, complex calculation management. Inspiration: a well-chosen algorithm can turn O(n²) work into O(n log n) — orders of magnitude less compute for the same result.
3. **The four sorts (~3 pg)** — For each of Selection, Bubble, Insertion, Merge: how it works (short walkthrough), code example, time complexity (best/avg/worst), and when to use it. Inspiration: Selection and Bubble are simple but quadratic; Insertion shines on nearly-sorted data; Merge guarantees O(n log n) at the cost of extra memory. Note the instructions also mention quick sorts — cover it in the processing-time discussion.
4. **Measuring processing time (~1 pg)** — How to measure required processing time: counting comparisons/swaps, benchmarking, and complexity analysis as prediction vs. stopwatch measurement.
5. **Big-O overview (~1.5 pg)** — What it is, how it works (dominant-term growth rate), strengths (hardware-independent comparison), weaknesses (ignores constants, best/avg/worst differences, memory usage). Show Big-O for each of your four sorts.
6. **Comparative analysis (~1 pg)** — A comparison table + recommendation: which sort for which dataset size/shape.
7. **Conclusion & references** — ≥5 scholarly sources (textbook + peer-reviewed algorithm papers).
