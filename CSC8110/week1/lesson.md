### Assignment 1 — Analyze the Evolution of Programming Languages (Part 1)
**Due: Nov 1, 2026 11:59 PM · 10 points · Turnitin enabled**

#### Assignment Instructions
Write an academic paper analyzing the evolution of programming languages — from switches and machine languages to high-level languages. Your paper must contain:

- A timeline of the generations of programming languages (created by you, not internet images), with the major languages of each generation.
- A discussion of the use, strengths, and weaknesses of each generation, including **at least 3 languages per generation**.
- A discussion of the role of Java's bytecode and .NET's intermediate-language code, and how performance can be improved by refining code and using functions and libraries.
- A general matrix comparing each language's syntax and semantic structure, identifying the purpose/solution where each is most commonly used.
- A conclusion.
- **Length:** 6–8 pages (excluding cover and references) · **References:** ≥5 scholarly resources · APA.

#### Assignment Outline & Writing Inspiration
1. **Introduction (~0.5 pg)** — Hook: 500+ languages invented; each with its own specification, syntax, and features. Frame the question: why did languages evolve, and what does each generation solve?
2. **Timeline of generations (~1 pg)** — Build your own table/diagram: 1st gen machine/assembly → 2nd gen (Fortran, COBOL) → 3rd gen (C, Pascal) → 4th gen/OO (C++, Java) → modern (Python, Swift). Tip: use the attached TIM-8110 Evolution table as your factual spine.
3. **Generation-by-generation analysis (~2.5 pg)** — For each generation: its use, strengths, weaknesses, and ≥3 languages with examples. Inspiration: contrast abstraction level, portability, execution speed, and programmer productivity across generations.
4. **Bytecode & IL (~1 pg)** — Explain how Java bytecode and .NET IL decouple source from hardware (write once, run anywhere), JIT compilation, and how refined code, functions, and libraries improve performance.
5. **Comparison matrix (~1 pg)** — Table: language × {syntax structure, semantic structure, common purpose/solution}. Fill from your generation analysis so the matrix and prose agree.
6. **Conclusion (~0.5 pg)** — Synthesize the trend (toward abstraction, safety, productivity) and recommend how to choose a language today.
7. **References** — ≥5 scholarly sources (the Princeton evolution paper, textbook, and peer-reviewed articles are good candidates).
