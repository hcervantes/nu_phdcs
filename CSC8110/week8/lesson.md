## Assignment Due This Week

### Assignment 8 — Signature Assignment: Create Standards for Design and Development
**Due: Dec 20, 2026 11:59 PM · 25 points · Turnitin enabled**

#### Assignment Instructions
**Scenario:** Your CEO met Google and Apple representatives at a conference presenting cloud computing benefits, and asked you, as senior solutions architect, to analyze current company applications and the potential of switching to cloud-based applications.

**Part I — Technical paper (15–20 pages).** Create corporate standards for database and application design and development (naming standards, formatting structure, etc.), including recommendations for programming languages and development platforms. The document must include:

- Cover page, table of contents, abstract
- Introduction reflecting on the importance of cloud computing and associated security threats
- Goal statement
- Comparison of the main applications currently used with the cloud applications you will switch to
- Recommended data management approaches for efficient data access/handling from the proposed solutions (local and mobile/cloud) for ERP and EHR implementations
- Discussion of the structure of each proposed algorithm and programming language, with corresponding technical specifications for installation and configuration
- Naming and coding standards based on the programming language recommendations
- Applied examples of at least one solution each for: in-house development, ERP solutions, packaged software implementations, and mobile applications
- Conclusion — final reflection on the proposal, expected results, and recommendations for further steps or research

**Part II — Presentation (10–15 slides with recording).** Explain the current solutions and the future cloud/mobile solutions, including all benefits/drawbacks for both.

**References:** ≥5 scholarly references · APA.

#### Assignment Outline & Writing Inspiration
1. **Front matter** — Cover page, table of contents, abstract (one paragraph summarizing the whole proposal).
2. **Introduction & goal statement (~1.5 pg)** — The CEO's cloud mandate; importance of cloud computing plus its security threats (use the LetMeInTheCloud survey: security 93.8%, governance 61.1%, data loss 73.5%). State measurable goals: standardization, cost, scalability, security.
3. **Current vs. proposed applications (~2.5 pg)** — Table comparing each main current application with its cloud replacement: function, cost, integration, security, migration risk.
4. **Data management approaches (~2.5 pg)** — For ERP and EHR: efficient access and handling for local, mobile, and cloud solutions. Inspiration: API-led integration, data warehouses/lakes, encryption at rest/in transit, HIPAA/HITECH obligations for EHR data.
5. **Algorithm & language structures (~3 pg)** — Structure of each proposed algorithm and programming language with technical specifications for installation and configuration (e.g., Java + JVM, Python + runtime, C#/.NET + CLR; database engines; cloud platform services).
6. **Naming & coding standards (~2.5 pg)** — Concrete, fully developed standards based on your language recommendations: naming conventions (tables, columns, classes, functions, files), formatting, version-control workflow, code review. The 30% criterion explicitly rewards "fully developed" standards — give examples of right vs. wrong.
7. **Applied examples (~3 pg)** — One worked example each: in-house development, ERP solution, packaged software implementation, mobile application.
8. **Conclusion (~1 pg)** — Reflection, expected results, further steps/research.
9. **Part II presentation** — 10–15 slides with narration: current solutions → proposed cloud/mobile solutions → benefits/drawbacks of both → recommendation.
