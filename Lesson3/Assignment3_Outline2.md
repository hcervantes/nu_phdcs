#### **📌 2. Differentiating Data, Information, and Metadata** *(~1 page)*
**Purpose:** Define and contrast the three terms with examples.
- **2.1 Data**
  - Definition: Raw facts (structured/unstructured).
  - Example: Customer records in a CSV file (structured); social media posts (unstructured).
- **2.2 Information**
  - Definition: Data in context (analyzed, visualized, or reported).
  - Example: A dashboard showing customer churn trends derived from raw data.
- **2.3 Metadata**
  - Definition: "Data about data" (descriptive, structural, administrative).
  - Example: File creation date (administrative); table schema (structural).
- **Comparison Table:**
  | **Aspect**       | **Data**               | **Information**          | **Metadata**            |
  |------------------|------------------------|--------------------------|-------------------------|
  | **Definition**   | Raw facts              | Contextualized data     | Describes data attributes |
  | **Example**      | Sales transaction logs | Monthly sales report    | Author, date created     |
